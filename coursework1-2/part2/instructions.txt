The backend API base URL is controlled by the BACKEND environment variable.

If BACKEND is not set, the server defaults to http://localhost:8181, which matches the provided test server.

To run locally with the tester:

    Start the tester / backend on port 8181.

    Run npm start.

    Open http://localhost:8080 (client) and http://localhost:8080/display (display).

To use a different backend, set
BACKEND="https://your-backend-url" (and AZURE_API_KEY if needed) in app.yaml before running npm start or npm run gdeploy.
